# A. 数据库详细设计

> 版本：v1.0 | 基于 rules.md v2.3 第6章 + 第16章扩展
> 目标：可直接用于建库建表、指导 ORM 映射

---

## 一、选型与规范

### 1.1 存储矩阵

| 数据库 | 用途 | 引擎/配置 |
|--------|------|----------|
| **MySQL 8.0** | 主业务存储（结构化数据） | InnoDB, utf8mb4 |
| **Redis Cluster** | 缓存/会话/房间状态/排行榜/分布式锁 | 6主6从, aof+RDB |
| **MongoDB 6.0** | 回放数据(JSON)/操作日志 | Replica Set 3节点 |

### 1.2 命名规范

- **表名**：小写+下划线复数 → `users`, `wallet_ledgers`
- **主键**：`{表单数}_id` → `user_id`, `room_id`
- **索引**：`idx_{表}_{字段}` / 唯一 `uk_{表}_{字段}`
- **金额字段**：`bigint`（最小单位"分"或积分点）
- **时间字段**：`datetime`，统一 UTC
- **枚举字段**：`tinyint` / `varchar(16)`，COMMENT 注释所有取值

### 1.3 分库分表策略

```
game_platform_db
├── 核心库（不分片）：games, admin_roles/permissions, system_configs
├── 用户库 db_0~db_7 (user_id % 8)：users, devices, wallets, wallet_ledgers*(按月), safeboxes
├── 房间游戏库 db_room_0~db_3 (game_id)：rooms, room_players, game_rounds, actions, fee_ledgers
├── 运营库 db_ops：activities, channels, tickets, risk_events, announcements
├── 系统库 sys_db：audit_logs*(分区), versions, hotfixes, bugs, audio/vfx_resources
└── 归档库 archive_db（季迁移）
```

## 二、ER 关系图

```
games ──1:N─> game_rule_versions
rooms ──1:N─> room_players (N:1 users)
rooms ──1:N─> game_rounds ──1:N─> round_actions ──1:1─> game_replays(MongoDB)
users ──1:1─> wallets ──1:N─> wallet_ledgers*(月分表)
users ──1:1─> safeboxes
admin_users(N:1) ──> admin_roles(N:N) ──> admin_permissions(树形)
```

## 四、MongoDB 回放集合设计

```javascript
// Collection: game_replays
// Database: game_replay_db

{
  _id: ObjectId,
  round_id: NumberLong,              // MySQL game_rounds.id
  room_id: NumberLong,
  game_code: String,

  // 发牌信息
  deal_info: {
    seed_hash: String,               // SHA256
    dealer_seat: Number,
    initial_tiles: [
      { seat: 0, tiles: ["1w","2w",...] },
      { seat: 1, tiles: [...] }
    ]
  },

  // 操作流（核心）
  actions: [
    {
      step: Number,
      timestamp: ISODate,
      elapsed_ms: Number,
      seat: Number,
      player_id: String,
      action: String,                 // DRAW/DISCARD/CHI/PENG/GANG/HU/PASS/...
      data: {                         // 操作详情(依action不同)
        tile: String,
        tiles: [String],
        hu_type: String,
        score: Number
      },
      state_snapshot: {               // 局面快照(用于跳转)
        hands: [{ seat, tiles, count }],
        discards: [{ seat, tiles }],
        melds: [{ seat, type, tiles }]
      }
    }
  ],

  // 最终结算(冗余便于查询)
  settlement: {
    players: [{ user_id, seat, final_score, hu_types, gang_count }],
    end_reason: String
  },

  created_at: ISODate
}

// 索引
db.game_replays.createIndex({ round_id: 1 }, { unique: true });
db.game_replays.createIndex({ room_id: 1, created_at: -1 });
db.game_replays.createIndex({ "settlement.players.user_id": 1 });
```

## 六、枚举值速查表

### 用户状态 users.status
| 值 | 含义 |
|----|------|
| 0 | 已注销(仅查历史) |
| 1 | 正常 |
| 2 | 冻结(可解冻或设截止时间) |
| 3 | 封禁(需人工审核解封) |

### 钱包类型 wallets.wallet_type
| 值 | 说明 | 可提现 |
|----|------|--------|
| fun_score | 娱乐积分 | 否 |
| match_score | 比赛积分 | 否 |
| room_card | 房卡 | 否 |
| activity_coupon | 活动券 | 否 |
| safebox | 保险箱积分(逻辑上独立) | 否 |

### 流水类型 change_type
| 值 | 方向 |
|----|------|
| GAME_WIN | + |
| GAME_LOSE | - |
| ROOM_FEE | - |
| ACTIVITY_REWARD | + |
| ADMIN_ADJUST | +/- |
| SAFEBOX_IN | -(钱包) |
| SAFEBOX_OUT | +(钱包) |
| COMPENSATION | +(后台补偿) |

### 房间状态 rooms.status
| 值 | 说明 |
|----|------|
| WAITING | 等待玩家加入 |
| READY | 人满全部准备 |
| PLAYING | 游戏中 |
| SETTLING | 结算中 |
| FINISHED | 正常结束 |
| DISSOLVED | 投票解散 |
| EXCEPTION | 异常中断(断线等) |

### 牌局状态 game_rounds.status
| 值 | 说明 |
|----|------|
| PLAYING | 进行中 |
| SETTLING | 结算中 |
| FINISHED | 已完成 |
| CANCELLED | 已取消(如解散) |

### 操作类型 action_type
| 值 | 适用游戏 |
|----|---------|
| READY | 全部 |
| DRAW | 全部(摸牌/发牌) |
| DISCARD | 全部(出牌) |
| CHI | 麻将(吃)/歪胡子(吃) |
| PENG | 麻将/歪胡子(碰) |
| GANG | 麻将/歪胡子(杠)/千分(?可选) |
| HU | 麻将(胡)/歪胡子(胡) |
| PAO | 歪胡子(跑) |
| WEI | 歪胡子(偎) |
| TI | 歧胡子(提) |
| PASS | 全部(过/不要) |
| DISSOLVE_VOTE | 全部(解散投票) |
| AUTO_PLAY | 全部(托管自动出牌) |

### 风控等级 risk_level
| 值 | 含义 | 默认动作 |

| 1 | 中(观察) | mark_observed |
| 2 | 高(可疑) | limit_match |

### 规则版本状态 status
| 值 | 含义 |
|----|------|

| 1 | 待审批 |
| 2 | 已生效 |
| 3 | 已废弃 |
